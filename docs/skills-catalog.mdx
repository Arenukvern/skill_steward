# Skills Catalog

All installable meta-skills shipped by Skill Steward. Descriptions are sourced from each skill's `SKILL.md` frontmatter — the source of truth lives in [`skills/`](https://github.com/arenukvern/skill_steward/tree/main/skills).

```bash
# Install all meta-skills
npx skills add arenukvern/skill_steward

# Install one skill by name
npx skills add arenukvern/skill_steward --skill <name>
```

See [DX_FAQ](DX_FAQ) for full install, update, and listing commands.

## Marketplace

*Authoring, reviewing, and publishing skills for the Skill Steward marketplace.*

| Skill | What it does |
|-------|-------------|
| [`create-skill`](https://github.com/arenukvern/skill_steward/tree/main/skills/create-skill) | Scaffold a new Agent Skill with valid SKILL.md, directory layout, and registry entries. Use when adding a skill or contributing to skill_steward. |
| [`skill-spec-review`](https://github.com/arenukvern/skill_steward/tree/main/skills/skill-spec-review) | Audit SKILL.md and skill directories for Agent Skills spec, Cursor extensions, and npx skills compatibility. Use when reviewing or checking marketplace readiness. |
| [`skill-source-citations`](https://github.com/arenukvern/skill_steward/tree/main/skills/skill-source-citations) | Requires durable citations when authoring skills — maintain `references/sources.md` per skill, link external research, and record provenance. |
| [`skill-eval-improve`](https://github.com/arenukvern/skill_steward/tree/main/skills/skill-eval-improve) | Improves Agent Skills via validate → rule-based eval cases → plugin-eval → prompt evals → bounded edits with held-out gates. |
| [`plugin-marketplace-setup`](https://github.com/arenukvern/skill_steward/tree/main/skills/plugin-marketplace-setup) | Designs public or private AI skill and plugin marketplaces for Cursor, Claude Code, Codex, and npx skills. |
