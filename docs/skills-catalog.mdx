# Skills Catalog

All installable stewardship skills shipped by Skill Steward. Each skill's `SKILL.md` frontmatter remains the source of truth in [`skills/`](https://github.com/arenukvern/skill_steward/tree/main/skills). Run `pnpm run list` for the current local view.

```bash
npx skills add arenukvern/skill_steward
npx skills add arenukvern/skill_steward --skill <name>
npx skills add <workspace>/agent_guild -a cursor -a claude-code -a codex -a zed -y
```

See [DX_FAQ](DX_FAQ) for full install, update, and listing commands.

`npx skills` is the public install/update path. `steward install/update` is for repo-local `skills.json` registration, agent folder layout, and commit/ref pinning.

## Which skill should I use first?

| Situation | Start with | Then add |
|-----------|------------|----------|
| Any app, library, CLI/tool, plugin, harness, or meta repo needs stewardship | `repo-quality-system-lifecycle` | `repository-governance-lifecycle` for structural decisions |
| A standing decision, ADR, FAQ, or stale plan needs cleanup | `repository-governance-lifecycle` | `vision-alignment-foresight` when the direction itself is uncertain |
| A repo is ready for typed actions, probes, and benchmarks | `mcp-harness-repo-maintainer` | `harness-engineering-lifecycle` after H2 proof exists |
| A reusable Agent Skill is being authored or reviewed | `skill-authoring-lifecycle` | `skill-source-citations`, then `skill-eval-improve` |
| Release notes, versioning, or binary provenance is unclear | `release-changelog-harness` | `repo-quality-system-lifecycle` for the broader release contract |
| A complex decision needs multiple critical lenses | `mixture-of-experts` | `multi-agent-handoff` only when work moves between agents |

## Repository stewardship

*Structural governance and quality for apps, libraries, tools, plugins, harnesses, and meta repos.*

| Skill | What it does |
|-------|-------------|
| [`repo-quality-system-lifecycle`](https://github.com/arenukvern/skill_steward/tree/main/skills/repo-quality-system-lifecycle) | Establishes or audits a repo quality contract: charter, docs lattice, type-native gates, evidence, action safety, maturity proof, and feedback loops. |
| [`repository-governance-lifecycle`](https://github.com/arenukvern/skill_steward/tree/main/skills/repository-governance-lifecycle) | Guides architectural decisions, ADRs, FAQs, stale-plan cleanup, ethics, and brand-tone governance. |
| [`vision-alignment-foresight`](https://github.com/arenukvern/skill_steward/tree/main/skills/vision-alignment-foresight) | Critically analyzes vision vs application reality, user intent, evidence, and likely future direction before committing to a roadmap. |

## Harness and action contracts

*Agent-first engineering culture: CLI, MCP, typed actions, contracts, and docs as system of record.*

| Skill | What it does |
|-------|-------------|
| [`mcp-harness-repo-maintainer`](https://github.com/arenukvern/skill_steward/tree/main/skills/mcp-harness-repo-maintainer) | Maintains repo-local action contracts and harnesses through `steward.yaml`, typed actions, quick probes, benchmark smoke loops, CLI/MCP parity, and in-repo docs. |
| [`harness-engineering-lifecycle`](https://github.com/arenukvern/skill_steward/tree/main/skills/harness-engineering-lifecycle) | Generalizes existing validation harnesses across producer-consumer boundaries and safely dogfoods them in sibling repos. |

## Skill lifecycle and distribution readiness

*Authoring, reviewing, evaluating, and publishing Agent Skills and plugin wiring.*

| Skill | What it does |
|-------|-------------|
| [`skill-authoring-lifecycle`](https://github.com/arenukvern/skill_steward/tree/main/skills/skill-authoring-lifecycle) | Scaffold and formally review Agent Skills with valid `SKILL.md`, resource planning, sources, evals, registry entries, and marketplace readiness. |
| [`skill-source-citations`](https://github.com/arenukvern/skill_steward/tree/main/skills/skill-source-citations) | Requires durable citations when authoring skills — maintain `references/sources.md` per skill, link external research, and record provenance. |
| [`skill-eval-improve`](https://github.com/arenukvern/skill_steward/tree/main/skills/skill-eval-improve) | Improves Agent Skills via validate, rule-based eval cases, plugin-eval, prompt evals, and bounded edits with held-out gates. |
| [`plugin-marketplace-setup`](https://github.com/arenukvern/skill_steward/tree/main/skills/plugin-marketplace-setup) | Designs public or private Agent Skill and plugin distribution for Cursor, Claude Code, Codex, Zed, Open Plugin, and `npx skills`. |
