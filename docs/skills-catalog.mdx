# Skills Catalog

All installable stewardship skills shipped by Skill Steward. Each skill's `SKILL.md` frontmatter remains the source of truth in [`skills/`](https://github.com/arenukvern/skill_steward/tree/main/skills). Run `pnpm run list` for the current local view.

```bash
npx skills add arenukvern/skill_steward
npx skills add arenukvern/skill_steward --skill <name>
```

Maintainer local override while iterating before release:

```bash
npx skills add <skill-steward-checkout> -a cursor -a claude-code -a codex -a zed -y
```

See [DX_FAQ](DX_FAQ) for full install, update, and listing commands.

`npx skills` is the public install/update path. `steward install/update` is for repo-local `skills.json` registration, agent folder layout, and commit/ref pinning.

## Which skill should I use first?

Standing procedure: [work discipline](core/work-discipline).

| Situation | Skill |
|-----------|--------|
| Adopt or audit a repo contract | `repo-quality-system-lifecycle` |
| ADR, FAQ, plan, MoE, vision, continuity, docs, or a public story | `repository-governance-lifecycle` |
| Move one obligation to another agent | `multi-agent-handoff` |
| Author a skill, evals, or citations | `skill-authoring-lifecycle` |
| Local harness contract through cross-repo proof | `harness-engineering-lifecycle` |
| Release, changelog, or marketplace install | `release-changelog-harness` |

The former `mixture-of-experts`, `vision-alignment-foresight`, `steward-continuity-boundary-lifecycle`, `docs-refresh-lifecycle`, `storytelling-ethics-lifecycle`, `mcp-harness-repo-maintainer`, `skill-eval-improve`, `skill-source-citations`, and `plugin-marketplace-setup` directories were removed in 0.6.0; their procedures live in the guild skills below.

## Philosophy before skills

Installable skills are procedures. The worldview that makes them make sense lives in Core Concepts. If you installed skills without the docs tree, two skills ship portable digests under `references/`: `repo-quality-system-lifecycle` and `repository-governance-lifecycle`. Full essays stay on docs.page.

| Concept | One-line | Skills that apply it |
|---------|----------|----------------------|
| [Evolutionary simplicity](https://docs.page/arenukvern/skill_steward/core/evolutionary-simplicity) | Evolve toward lower future confusion — not always fewer parts | `repo-quality-system-lifecycle`, `repository-governance-lifecycle` |
| [Generational architecture ladder](https://docs.page/arenukvern/skill_steward/core/generational-architecture-ladder) | Choose the smallest useful layer (G0–G5); higher is not automatically better | `repo-quality-system-lifecycle`, `repository-governance-lifecycle` |
| [Stewardship loop](https://docs.page/arenukvern/skill_steward/core/stewardship-loop) | Observe → decide → update → prove → preserve | All stewardship skills; charter in [North Star](https://docs.page/arenukvern/skill_steward/NORTH_STAR) |

When deciding whether to split, compress, promote, demote, delete, or stay native, start with `repo-quality-system-lifecycle` and read its concept digests first.
