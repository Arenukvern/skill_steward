## Action Contract Note

The protocol smoke action does not use `dart run`. It invokes the script with an explicit package config:

```bash
dart --packages=packages/steward_cli/.dart_tool/package_config.json \
  packages/steward_cli/bin/steward.dart protocol validate \
  --mode-events .steward/events.example.jsonl \
  --self-model .steward/self-model.example.json \
  --json
```

This keeps the action contract read-only for quick probe use. `packages/steward_cli/.dart_tool/package_config.json` is declared as an input. Dependency resolution remains outside this action and belongs to maintainer setup or validation commands that already declare Dart cache writes.
