# Current dogfood reproducibility

This card is the public/auditable subset of dogfood evidence. It does not replace [Current dogfood status](current-dogfood-status), which remains the current source for weakest true claims, blockers, rerun routes, and maintainer-local diary context.

Use this card to decide whether a claim can be checked without one maintainer's workstation. A public proof row needs durable repo URLs, fetchable commit SHAs, repo-relative or placeholder-based commands, artifact names or hashes, limitations, and non-claims.

## Public proof bar

| Field | Requirement |
|-------|-------------|
| Durable source | Public repository URL plus fetchable commit SHA for the subject under test. |
| Reproducible command | Repo-relative command or placeholder-based command such as `cd <skill-steward-checkout> && steward ...`. |
| Proof artifact | Checked-in artifact path, CI artifact name, or artifact hash. |
| Claim boundary | Exact claim, limitations, and non-claims. |
| Current status pointer | Link back to [Current dogfood status](current-dogfood-status). |
