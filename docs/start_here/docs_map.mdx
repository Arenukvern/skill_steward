## Executable truth

Docs should point here instead of paraphrasing behavior.

| Behavior | Executable owner | Notes |
|----------|------------------|-------|
| Maintainer commands | [`package.json`](https://github.com/arenukvern/skill_steward/blob/main/package.json) | Script names are the command SSOT; DX_FAQ explains usage. |
| Steward CLI behavior | [`packages/steward_cli/`](https://github.com/arenukvern/skill_steward/tree/main/packages/steward_cli) | Dart code is the runtime truth for validate/eval/list/contract commands. |
| Repo-local contract | [`steward.yaml`](https://github.com/arenukvern/skill_steward/blob/main/steward.yaml) | Declares local actions, probes, evidence policy, and descriptive suites. |
| Portable data shapes | [`docs/schemas/*.json`](../schemas/README) | JSON Schema covers shape; Dart validators enforce cross-field and repo-state rules. |
| Tier-1 skill routing | [`packages/steward_cli/lib/src/eval/eval_tiers.dart`](https://github.com/arenukvern/skill_steward/blob/main/packages/steward_cli/lib/src/eval/eval_tiers.dart) + `skills/*/evals/cases/*.yaml` | Eval tier list and case files are the CI gate. |
| Skill/package validation | [`packages/steward_cli/lib/src/validation/`](https://github.com/arenukvern/skill_steward/tree/main/packages/steward_cli/lib/src/validation) | `docs/STANDARDS.mdx` explains the contract; validators enforce it. |
| Benchmark scenarios | [`steward/scenarios/`](https://github.com/arenukvern/skill_steward/tree/main/steward/scenarios) | Durable execution proof is blocked unless contract inputs are clean and tracked. |
| CI/release gates | [`.github/workflows/`](https://github.com/arenukvern/skill_steward/tree/main/.github/workflows) | Workflow files define what remote automation actually runs. |
